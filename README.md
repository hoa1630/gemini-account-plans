几条实操上的硬要求：

- **必须全局模式，不要 PAC 或规则模式。** 规则模式下部分 Google 请求会走直连，真实 IP 暴露，登录 IP 和真实 IP 对不上，是风控的高频触发点。
- **用美国节点，登录前后国家保持一致。** 今天美国、明天日本地切，等于自己举报自己。
- **公共机场节点基本是重灾区。** 同一个 IP 上可能同时有几十个 Google 账号在登录，风控一眼就能识别。有条件就上住宅 IP 或独享静态 IP。

- **固定设备。** 短时间内手机、电脑、平板轮流登，也是异常信号。
